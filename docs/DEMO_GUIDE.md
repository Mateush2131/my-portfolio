# Демонстрация работы сайта

## Пошаговая инструкция для проверки

### 1. Главная страница
- Открыть http://91.135.157.42
- Проверить анимации (звёзды, луна, лес)
- Проверить адаптив (F12 → Device Toolbar → 375px)

### 2. Бургер-меню
- Нажать на иконку в правом верхнем углу
- Должно открыться полноэкранное меню
- Кликнуть на пункт — плавный скролл к секции

### 3. Форма заявки
- Заполнить поля (любые данные)
- Нажать "Отправить"
- Появится сообщение "✅ Заявка отправлена!"

### 4. Админ-панель
- Перейти на /admin
- Ввести логин: admin, пароль: secret
- Увидеть таблицу с заявками
- Изменить статус заявки
- Удалить заявку

### 5. База данных (Supabase)
- Зайти в Supabase Dashboard
- Table Editor → Order
- Новая заявка должна появиться в таблице
